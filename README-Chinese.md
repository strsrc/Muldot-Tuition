# 多点儿学习中心

本项目是 [多点儿学习中心](https://www.muldot.com/zh) 的官方源代码仓库，基于全球领先的开源电商平台 **nopCommerce** 深度定制开发。我们通过技术手段优化教育资源配置，为新加坡的学生提供一站式的学习支持方案。

## 🌟 关于多点儿学习中心

**多点儿学习中心** 是一个集补习老师匹配、优质学习资料下载及教学视频观看于一体的综合性教育平台。我们致力于通过科学的教学方法和智能化的工具，帮助各阶段学生高效掌握知识，突破学习难点。

## 📚 全学科覆盖

我们汇集了新加坡最优秀的家庭补习老师，覆盖从学前教育、小学、中学到初级学院（JC）、IB 及 IGCSE 的全阶段课程，重点教学科目包括： **华文 (Chinese)**、 **英文 (English)**、**数学 (Mathematics)** 、 **科学 (Science)**、 **物理 (Physics)**、**化学 (Chemistry)** 及 **经济学 (Economics)**。

## 🚀 核心服务特色

1. **金牌老师精准匹配**：所有导师均经过严格筛选，拥有三年以上教学经验，专业且富有热情。
2. **三步极速预约**：用户只需“提交需求、互相确认、开始上课”三个简单步骤，即可找到符合预算与需求的优质导师。
3. **海量学习资源**：提供包括**名校试卷**、**名师题库**、备考资料及儿童绘本在内的丰富下载资源。
4. **多维度教学视频**：包含提分技巧分享、录播课程以及互动的线上直播课程。

## 🛠 技术背景：基于 nopCommerce

本项目 fork 自 **nopCommerce** 官方仓库。我们利用其卓越的架构实现了教育资源的高效管理与展示。

- **底层架构**：基于 **ASP.NET Core (.NET 8)**，具备极高的稳定性和安全性。
- **灵活扩展**：利用其可插拔的清晰架构，我们定制开发了独特的补习老师预约系统和学习资料付费下载功能。
- **高性能**：全异步（Async）方法支持，确保在大量用户同时在线搜索老师或下载资料时依然流畅。
