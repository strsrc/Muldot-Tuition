# Muldot Learning Centre

This project is the official source code repository of [Muldot Learning Centre](https://www.muldot.com/zh), deeply customised from the world's leading open-source e-commerce platform **nopCommerce**. We optimise the allocation of educational resources through technology, providing one-stop learning/tuition support for students in Singapore.

## 🌟 About Muldot Learning Centre

**Muldot Learning Centre** is a comprehensive education platform integrating tuition, tutor matching, quality learning material downloads, and instructional video viewing. We are dedicated to helping students at all stages master knowledge efficiently and overcome learning difficulties through scientific teaching methods and intelligent tools.

## 📚 Full Subject Coverage

We bring together the best home tutors in Singapore, covering all stages from preschool, primary school, secondary school to junior college (JC), IB, and IGCSE. Key teaching subjects include: **Chinese**, **English**, **Mathematics/Maths**, **Science**, **Physics**, **Chemistry**, and **Economics**.

## 🚀 Core Service Features

1. **Precise Matching of Premium Tutors**: All tutors are rigorously screened, with over three years of teaching experience – professional and passionate.
2. **3-Step Fast Booking**: In just three simple steps – “submit request, mutual confirmation, start class” – users can find a quality tutor that fits their budget and needs.
3. **Extensive Learning Resources**: Provides rich downloadable resources including **top school exam papers**, **premium question banks**, exam preparation materials, and children’s picture books.
4. **Multi-Format Instructional Videos**: Includes exam tips, recorded courses, and interactive live classes.

## 🛠 Technology Background: Built on nopCommerce

This project is forked from the official **nopCommerce** repository. We leverage its outstanding architecture to achieve efficient management and presentation of educational resources.

- **Core Framework**: Built on **ASP.NET Core (.NET 8)** – highly stable and secure.
- **Flexible Extensibility**: Using its pluggable clean architecture, we have custom‑developed a unique tutor booking system and a paid learning material download feature.
- **High Performance**: Fully asynchronous methods ensure smooth performance even when a large number of users search for tutors or download materials simultaneously.
